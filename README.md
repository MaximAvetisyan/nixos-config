# NixOS config

User `max`. Two install targets: bare-metal desktop (Hyprland) and WSL2 (slim CLI).

## 1. Bare metal

The config is expected at `~/.config/nixos-config/`:

- `configuration.nix` — system config (imports `hardware-configuration.nix`)
- `home.nix` — home-manager config (Hyprland, waybar, ghostty, zsh, tmux)
- `hardware-configuration.nix` — generated by `nixos-generate-config`

To make `nixos-rebuild` see it, point `/etc/nixos` at it, then rebuild:

```sh
sudo ln -sfn ~/.config/nixos-config/configuration.nix /etc/nixos/configuration.nix
sudo ln -sfn ~/.config/nixos-config/hardware-configuration.nix /etc/nixos/hardware-configuration.nix
sudo nixos-rebuild switch
```

Rebuild any time with `update` (alias for `sudo nixos-rebuild switch`), clean
up old generations with `clean`.

## 2. WSL

The flake lives at `~/.config/nixos-config/` and defines the `wsl` output.
Install it with:

```sh
sudo nixos-rebuild switch --flake ~/.config/nixos-config#wsl
```

Rebuild with the `update` alias, clean up with `clean`. New shells also get
`cs` (tmux session with nvim, zsh, opencode).

To build the WSL image on any Nix machine, run from `~/.config/nixos-config`:

```sh
nix flake lock
sudo nix run .#nixosConfigurations.wsl.config.system.build.tarballBuilder
```

Result is `./nixos.wsl`. Import it on Windows (WSL >= 2.4.4): double-click the
file or run `wsl --install --from-file nixos.wsl`, then `wsl -d NixOS` and
`sudo passwd max`.
